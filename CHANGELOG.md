# История изменений

## 1.1.0 — 2026-11-12

- Интерфейс переработан в минималистичном стиле файловых менеджеров вроде nnn.
- Убраны громоздкие заголовки, колонки с датами и постоянные длинные сообщения.
- Добавлена установка исполняемой команды `sss` в `$PREFIX/bin`.
- Добавлены параметры `--install`, `--uninstall`, `--version` и `--help`.
- Добавлен запуск сразу в указанной папке: `sss ПУТЬ`.
- Добавлена компактная подсказка клавиш внизу экрана.

## 1.0.0 — 2026-11-12

- Первый самостоятельный релиз SSS File Manager для Termux.
- Добавлена навигация по каталогам с помощью стрелок.
- Добавлен текстовый предпросмотр файлов.
- Добавлены создание, переименование и безопасное удаление объектов.
- Добавлено отображение скрытых файлов, размера и даты изменения.
- Убрана зависимость от Suyziss Termux Toolkit: файловый менеджер запускается отдельно.
