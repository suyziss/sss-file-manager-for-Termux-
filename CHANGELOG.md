# История изменений

## 1.0.0 — 2026-11-12

- Первый самостоятельный релиз SSS File Manager для Termux.
- Добавлена навигация по каталогам с помощью стрелок.
- Добавлен текстовый предпросмотр файлов.
- Добавлены создание, переименование и безопасное удаление объектов.
- Добавлено отображение скрытых файлов, размера и даты изменения.
- Убрана зависимость от Suyziss Termux Toolkit: файловый менеджер запускается отдельно.
