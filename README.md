# SSS File Manager for Termux

**Версия: 1.0.0**

Лёгкий файловый менеджер с TUI-интерфейсом для Termux на Android. Управление стрелками клавиатуры, без root, без сторонних Python-библиотек.

## Возможности

- Навигация по папкам стрелками ← ↑ ↓ →.
- Открытие папок и текстовый предпросмотр файлов (до 160 строк).
- Создание папок и пустых файлов.
- Переименование файлов и папок.
- Удаление файлов и только пустых папок с подтверждением.
- Показ и скрытие скрытых файлов.
- Отображение размера и даты изменения.
- Запуск в текущей или указанной папке.

## Установка

В Termux выполни:

```bash
pkg update
pkg install python git
git clone https://github.com/suyziss/sss-file-manager-for-Termux-.git
cd sss-file-manager-for-Termux-
python sss_file_manager.py
```

Чтобы открыть общую память Android, сначала выдай Termux доступ:

```bash
termux-setup-storage
python sss_file_manager.py ~/storage/shared
```

## Управление

| Клавиша | Действие |
|---|---|
| ↑ / ↓ | Перемещение по списку |
| ← / Backspace | Перейти в родительскую папку |
| → / Enter | Открыть папку или предпросмотр файла |
| N | Создать папку |
| F | Создать пустой файл |
| R | Переименовать выбранный объект |
| D | Удалить файл или пустую папку (с подтверждением) |
| . | Показать / скрыть скрытые файлы |
| ? | Справка |
| Q | Выход |

## Требования

- Termux на Android.
- Python 3.9 или новее.
- Интерактивный терминал.
- Дополнительные Python-пакеты и root не требуются.

## Безопасность

Менеджер не удаляет непустые папки. Удаление файла или пустой папки требует подтверждения. Предпросмотр предназначен для текстовых файлов; бинарные файлы могут отображаться некорректно.
