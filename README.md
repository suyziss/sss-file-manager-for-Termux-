# SSS File Manager for Termux

**Версия: 1.1.1**

Минималистичный файловый менеджер для Termux в духе `nnn`: компактный список, путь сверху, подсказки клавиш снизу. Управление с клавиатуры, без root и сторонних Python-библиотек.

## Установка

```bash
pkg update
pkg install python git
git clone https://github.com/suyziss/sss-file-manager-for-Termux-.git
cd sss-file-manager-for-Termux-
python sss_file_manager.py
```

Чтобы открывать общую память Android:

```bash
termux-setup-storage
python sss_file_manager.py ~/storage/shared
```

## Установка команды sss

После клонирования проекта выполни:

```bash
python sss_file_manager.py --install
```

Теперь файловый менеджер запускается как обычная команда из любой папки:

```bash
sss
sss ~/storage/shared
sss /sdcard/Download
```

Команда устанавливается в `$PREFIX/bin/sss` и запускает Python-скрипт из папки проекта. Поэтому не перемещай и не удаляй папку проекта после установки команды.

Удаление только команды запуска:

```bash
sss --uninstall
```

Файлы проекта при этом остаются на месте.

## Управление

| Клавиша | Действие |
|---|---|
| ↑ / ↓ | Перемещение |
| ← / Backspace | Родительская папка |
| → / Enter | Открыть папку или предпросмотр файла |
| h | Показать / скрыть скрытые файлы |
| n | Создать папку |
| f | Создать пустой файл |
| r | Переименовать |
| d | Удалить файл или пустую папку с подтверждением |
| ? | Справка |
| q | Выход |

## Дополнительно

```bash
sss --version
sss --help
```

Предпросмотр текстовых файлов показывает до 160 строк. Непустые папки не удаляются. Бинарные файлы не предназначены для текстового предпросмотра.

## Требования

- Termux на Android.
- Python 3.9 или новее.
- Интерактивный терминал.
- Root и дополнительные Python-пакеты не нужны.
